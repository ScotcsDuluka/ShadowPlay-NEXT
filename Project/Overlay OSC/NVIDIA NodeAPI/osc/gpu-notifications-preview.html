OSC · GPU notification inventory

การแจ้งเตือน GPU ทั้งหมด

แสดงทุก toast กลุ่ม GPU ที่สร้างจริงในโค้ดปัจจุบัน พร้อมหน้าตาการ์ดและค่า ICO / TEXT / TEXTSUB / ขนาด ใช้ขนาดตามที่ระบุและแสดงไอคอน EXE แบบไม่มีกรอบ ใช้แอป Smash_Legends.exe และ GPU ตัวอย่างเพื่อให้เห็นการตัดบรรทัด

Active toast groups: 3 เหตุการณ์ GPU: 4 รูปแบบ Runtime GPU toast: ปิด/ไม่มีผู้รับ event

รายการที่ไม่แสดงเป็น toast ตอนนี้

Runtime GPU (4 keys): gpuRuntimeStarted, gpuRuntimeChanged, gpuRuntimeMultiple, gpuRuntimeUnknown. ยังมีข้อความ l10n และ event validation อยู่ แต่ไม่มี notifier สมัครรับ Runtime GPU event ใน OSC ปัจจุบัน จึงไม่มี ICO / TEXTSUB / ขนาดการ์ดที่กำลังแสดงจริง (ตรงกับการปิดการตรวจ Runtime GPU ที่กำหนดไว้ก่อนหน้า)
