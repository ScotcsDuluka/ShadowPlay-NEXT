OSC · NVGRAPHICS-ADAPTER.JS

การ์ดทั้งหมดจาก NvGraphics-Adapter

หน้านี้แยกตามรูปแบบการ์ดที่ NvGraphics สร้างจริง โดยใช้ notifier CSS และองค์ประกอบ toast ชุดเดียวกับ runtime: การ์ดเกมบน GPU ที่ apply แล้ว, การตั้ง GPU เฉพาะแอป และการกลับไป System Default

3 รูปแบบการ์ด GPU notifications เปิด/ปิดได้ Updater UI: การ์ด preference

1. เกมกำลังทำงานบน GPU

คำนวณความกว้างจริง · สูง 90 px

เมื่อเกมปิดการ์ด OpenShare แล้ว และ NvGraphics พบ EXE ที่กำลังทำงานพร้อม per-app GPU override ที่ apply สำเร็จ

2. ตั้งแอปให้ใช้ GPU

คำนวณความกว้างจริง · สูง 90 px

เมื่อได้รับ GpuPreferenceApplied ใหม่ โดย isSystemDefault: false และการแจ้งเตือน GPU เปิดอยู่

3. กลับไปใช้ System Default

คำนวณความกว้างจริง · สูง 90 px

เมื่อได้รับ GpuPreferenceApplied ใหม่ โดย isSystemDefault: true และการแจ้งเตือน GPU เปิดอยู่

ขอบเขต: OpenShare ไม่รวมในหน้านี้ เพราะเป็นการ์ดของ OSC-Adapter.js. การ์ด GPU ตอนเริ่มเกมจะไม่แสดงหากไม่มี lastAppliedAdapterId.
